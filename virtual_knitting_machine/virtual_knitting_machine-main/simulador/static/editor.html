    Abra um arquivo

    Escolha um arquivo da pasta ao lado, use “Abrir do computador” ou arraste os arquivos para cá.

    • .dat desenho do KnitPaint: abre para edição.
    • .000 programa de tricô da máquina: abre para consulta.
    • .QFD ajustes automáticos: abre para consulta.
    • .png / .jpg imagem: pode ser importada num desenho.
